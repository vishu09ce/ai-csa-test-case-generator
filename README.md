# AI-Powered CSA Test Case Generator

A web-based Proof of Concept application that automatically generates FDA CSA-compliant validation documents from uploaded URS, BRD, and FRS source documents for Life Sciences organisations.

## Documents Generated
1. Software Assurance Plan (SAP)
2. Process Risk Assessment (PRA)
3. Requirements Traceability Matrix (RTM)
4. Scripted Test Protocol + Execution Record (STP)
5. Unscripted Test Record + Execution Record (UTR)
6. Assurance Summary Report (ASR)

## Tech Stack
- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Python + FastAPI
- **LLM Gateway:** LiteLLM
- **LLM Provider:** Groq
- **Database:** SQLite + SQLAlchemy
